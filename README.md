Dataset of Ancient Gurmukhi Manuscript Text Lines. This dataset contains 13,245 line images extracted from 1,896 pages of 43 handwritten Gurmukhi manuscripts (15th to 18th century), collected from Gurudwaras, private collections and the Punjab Digital Library. Each line image (.jpeg) has a ground-truth transcription (.txt) with the same file name. The transcriptions are in Gurmukhi script, exactly as written in the manuscripts, and the manuscripts have no spaces between words. The dataset also includes two synthetic datasets (25,904 and 18,423 line images). The language of the text is Punjabi (Gurmukhi script) and of the documentation is English.
